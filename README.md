# Online Clothing Store

Welcome to the **Online Clothing Store** project! This is a clothing e-commerce website built using HTML, Tailwind CSS, Custom CSS, PHP, and JavaScript. The project is designed with a responsive and modern interface to offer a seamless shopping experience.

You can check out the live version of the project here:  
[Online Clothing Store](https://tharushzzz.github.io/online-clothing-store/src/index.html)

## Features

- **Responsive Design**: The website is mobile-friendly and adjusts to different screen sizes.
- **Tailwind CSS**: Utilizes Tailwind for fast and efficient design and layout.
- **Custom CSS**: Custom styling to enhance the overall look and feel of the website.
- **PHP Integration**: Backend functionality to handle dynamic content.
- **JavaScript Interactivity**: Interactive elements such as the shopping cart, product details, and more.
- **Figma Design**: The UI design was created in Figma for a consistent and professional look.

## Technologies Used

- **HTML**: Structure and content of the website.
- **Tailwind CSS**: Utility-first CSS framework for building custom designs.
- **Custom CSS**: Personalized styles for specific components.
- **PHP**: Backend scripting for handling server-side logic.
- **JavaScript**: Adds dynamic functionality to the website, such as form validation and interactivity.
- **Figma**: UI/UX design tool used for the wireframes and layout.
